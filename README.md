# KICKER VHS 

**KICKER VHS** is a free VST3 distortion plugin designed specifically for processing **Hardcore, Gabber, and Hardstyle kicks**. 

It features a retro VHS/CRT menu interface and uses a smooth `tanh` soft-clipping algorithm to add analog-style warmth, grit, and saturation to your drums without harsh digital artifacts.

## Features
* **Drive:** Controls the input gain and distortion intensity (0–100%).
* **Tone:** A one-pole low-pass filter (20 Hz – 20 kHz) to shape the high-end harshness.
* **Mix:** Dry/Wet control (0–100%) for parallel processing.
* **Output:** Makeup gain (-24 dB to +6 dB).
* **Bypass:** Turn the effect on/off.
* **GUI:** Navigate using the Up/Down arrow keys to select a parameter, and Left/Right arrows to change the value. Press Enter/Space to toggle Bypass. You can also click and drag vertically on any line with your mouse.

## Installation (Windows)
1. Download the `KICKER VHS` ZIP archive from this repository.
2. Extract the archive.
3. Copy the entire `KICKER VHS` folder.
4. Paste it into the following directory:
   `C:\Program Files\Common Files\VST3\`
5. Open your DAW (FL Studio, Ableton, etc.), rescan your plugins, and start destroying your kicks
